Preprocessing Workflow Logic
Label Coordinate Preservation
Iterates over bounding box text files, parses normalized coordinates [x_center, y_center, width, height], and replaces the first column index without altering bounding geometry.
Multi-Class Disambiguation
Synonyms like "Sit Down" and "sitting" are mapped to 1. Rare edge actions (e.g. "Nearly_fall") are grouped into class 0 ("fall") to elevate sensitivity.
Collision-Free Unique Renaming
All images and label files receive prefix hashes (e.g., Stanford40_train_img014.jpg) before writing to prevent file overwrite collisions during consolidation.

Phase 3: Model Architecture

State-of-the-Art Neural Backbone: YOLO11 Nano

Why Ultralytics YOLO11n was selected: Maximum inference FPS, minimal memory footprint, and enhanced multi-scale attention.

YOLO11 Architectural Advances
C3k2 (Cross-Stage Partial) Blocks
Replaces legacy bottlenecks with dual small-kernel convolutions, reducing parameter count while accelerating gradient backpropagation.
C2PSA Spatial Attention Mechanism
Integrates Multi-Head Self-Attention inside the feature pyramid neck, capturing horizontal human body deformations characteristic of falls.
Anchor-Free Decoupled Head
Separates classification and bounding box regression branches, boosting mAP on extreme aspect ratios (e.g. prone bodies on floors).

Phase 4: Backend Serving

Asynchronous Inference Server with FastAPI

High-throughput microservice handling in-memory frame decoding, model execution, and low-latency JSON telemetry.

backend/main.py • REST API Endpoint
from fastapi import FastAPI, UploadFile, File from ultralytics import YOLO import cv2, numpy as np, time app = FastAPI(title="Fall Detection API") model = YOLO('best_v2.pt') @app.post("/detect/") async def detect_fall(file: UploadFile = File(...)): contents = await file.read() nparr = np.frombuffer(contents, np.uint8) img = cv2.imdecode(nparr, cv2.IMREAD_COLOR) start_time = time.time() results = model.predict(source=img, conf=0.5, verbose=False) latency = round(time.time() - start_time, 2) fall_detected = False boxes_data = [] for box in results[0].boxes: cls_name = model.names[int(box.cls[0])] if "fall" in cls_name.lower(): fall_detected = True x1, y1, x2, y2 = map(int, box.xyxy[0]) boxes_data.append({ "class_name": cls_name, "confidence": round(float(box.conf[0]), 2), "x1": x1, "y1": y1, "x2": x2, "y2": y2 }) return {"fall_detected": fall_detected, "boxes": boxes_data, "processing_time": latency}
Engineering Highlights
Zero-Disk In-Memory Buffer
Incoming frames are decoded directly from memory via np.frombuffer, eliminating expensive storage disk I/O bottlenecks.
CORS Middleware Enabled
Integrated CORSMiddleware allows cross-origin requests from web dashboards, mobile apps, and distributed edge nodes.

Returns execution time in milliseconds alongside detection coordinates for client-side FPS monitoring.

Verification & Validation

False Positive Suppression & Safety Interlocks

How multi-action contextualization prevents routine postures from triggering false emergency dispatches.

Intentional Lying Down

Challenge: An elderly individual resting on a bed or sofa has similar horizontal body aspect ratios to an accidental fall victim.

Solution: The model includes explicit lying and sitting classes trained on bed/furniture contexts, successfully discriminating restful states from ground falls.
Dynamic Confidence Tuning

Challenge: Different environments have varying tolerances for false positives vs. false negatives.

Solution: Admin slider allows adjusting confidence between 10% – 95% in real-time, tuning sensitivity to specific room layouts.
Alert Cooldown Engine

Challenge: Continuous 30 FPS video feeds could generate 1,800 alerts per minute for a single ongoing fall incident.

Solution: Stateful timestamp cooldown (3s / 5s / 10s) creates a single timestamped incident entry while maintaining live bounding boxes.
