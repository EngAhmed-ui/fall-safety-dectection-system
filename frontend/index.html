About AI Vision Guard

An enterprise-grade Fall Detection System powered by an optimized YOLO11 deep learning model and a robust FastAPI backend, designed for real-time human action recognition and critical incident alerting.

How It Works

The system continuously captures frames from live feeds or media files, processing them through our custom-trained YOLO model (trained on 8 distinct human states: Sitting, Standing, Walking, Lying, Desk Activity, Phone Interaction, Gestures, and Fall). By understanding normal behaviors, the system drastically reduces false positives when a real fall occurs.

Core Features

  • Dynamic Confidence Thresholding: A powerful administrative control that sets a minimum certainty percentage for fall alerts.
  • Smart Alert Cooldown: Prevents log spamming by enforcing a customizable delay.
  • Session Analytics: Real-time tracking of processing times, fall rates, and average confidence levels.
  • Desktop Notifications: Pushes browser alerts directly to the OS even if the dashboard is minimized.
